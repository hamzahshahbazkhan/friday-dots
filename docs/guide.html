Friday desktop setup

A repeatable install, a small maintenance routine, and a map of everyday controls.

Install on a new laptop

  1. Install Arch, create your regular user, enable networking, and give the user sudo access.
  2. Clone this repo and run the setup script:
git clone https://github.com/hamzahshahbazkhan/dots.git ~/dots
cd ~/dots
./bootstrap.sh --theme hamza

The script updates Arch, installs current repository and AUR packages, detects CPU/NVIDIA/Bluetooth hardware, applies dotfiles, and creates expected user folders. It may ask before changing your login manager, login shell, or Docker access. Keep your current display manager if it is already configured.

To skip optional changes:

./bootstrap.sh --theme hamza --non-interactive

This starts after Arch installation; it does not partition disks, create users, or configure firmware/UEFI.

Keep it current

Update Arch and AUR apps

paru -Syu

Review prompts before accepting package removals or replacements.

Update and apply dotfiles

cd ~/dots
git status
git pull --ff-only
./restore.sh --theme hamza

Config files are linked to the repo, so edits can change files you would pull or push. Check git status first.

Switch themes

./restore.sh --theme gruvbox
# or, after setup:
theme everforest

Follow the theme format and run ./scripts/check-themes.sh.

Arch is rolling release. The repo records package names and configuration, not package versions. A future install gets versions available then; it is not a byte-for-byte snapshot.

Where things live

  • bootstrap.sh installs packages and prepares a fresh Arch user.
  • restore.sh links configs and selects a theme without reinstalling packages.
  • packages/pacman.txt and packages/aur.txt list package names without version pins.
  • hypr/, quickshell/, scripts/, and app folders hold installed configuration.
  • themes/.config/themes/ holds theme palettes; wallpapers/ holds wallpaper files.

Optional Git display name/email settings go in a local .env copied from .env.example. Never put passwords, tokens, SSH keys, or app credentials in this repo. Use an SSH key or Git credential helper; sign in to apps on each device.

Quick fixes

  • Hyprland config changed: hyprctl reload.
  • Quickshell config changed: quickshell kill, then quickshell --daemonize.
  • Quickshell errors: quickshell log.
  • Quick controls need NetworkManager, power-profiles-daemon, and bluetooth.service running for Wi-Fi, power profiles, and Bluetooth.
  • Conflicting old config directories are backed up under ~/.config-backup-* by restore.sh.
Keep local edits and credentials backed up separately. Before sharing this repo, review git status and the staged diff.
